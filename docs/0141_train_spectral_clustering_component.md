# Spectral Clustering Component

**Script:** `train_spectral_clustering_component.py`

## Description
Evaluates a Spectral Clustering component mathematically in pure NumPy, testing its ability to cluster non-convex shapes like the Two Moons dataset using an RBF affinity matrix and normalized graph Laplacian.

## Results
The execution was successful. The component accurately clustered the non-convex two-moons data with 100% accuracy.
