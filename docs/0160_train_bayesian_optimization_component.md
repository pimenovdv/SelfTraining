# Bayesian Optimization Component

## Objective
Implement and evaluate a Bayesian Optimization component from scratch using pure NumPy to verify its effectiveness in finding the global minimum of an objective function.

## Implementation Details
The component uses a Gaussian Process (GP) as a surrogate model and Expected Improvement (EI) as the acquisition function to balance exploration and exploitation. The script evaluates the objective function iteratively.
