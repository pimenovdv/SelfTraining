# Tabular Q-Learning Component

**Script:** `train_q_learning_component.py`

This experiment validates the correct implementation of Tabular Q-Learning for solving finite Markov Decision Processes. It was tested on a deterministic 4x4 GridWorld environment.

The training algorithm converged correctly, effectively learning the optimal policy to navigate the grid and reach the goal state. The greedy testing successfully demonstrated optimal performance (6 steps minimum path length).

- **Success:** Yes
