# Simulated Annealing Component

**Script:** `train_simulated_annealing_component.py`

## Overview
This script implements Simulated Annealing mathematically in pure NumPy for function minimization, testing it on the Rosenbrock function.

## Mathematical Basis
Simulated Annealing is a probabilistic technique for approximating the global optimum of a given function. It is based on the metropolis-hastings algorithm and accepts worse solutions with a probability that decreases exponentially with the "temperature".

## Results
The implementation successfully minimized the Rosenbrock function, demonstrating optimization capability.
