# t-SNE Component

**Status:** Success

## Objective
Implement and evaluate a t-Distributed Stochastic Neighbor Embedding (t-SNE) component to reduce the dimensionality of data for visualization.

## Implementation Details
The component computes pairwise affinities in high-dimensional and low-dimensional space and minimizes the Kullback-Leibler divergence between these distributions using gradient descent.
