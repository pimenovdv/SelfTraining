# Spectral Clustering Component

## Objective
Implement and evaluate a Spectral Clustering component to partition data that is not linearly separable.

## Implementation Details
The component computes the affinity matrix, constructs the normalized Laplacian, extracts the eigenvectors, and applies K-means clustering on the transformed data space.
